# GENESIS-HACKATHON-MALIKA-NURZHAN-FULL-FINTECH-Project

Репозиторий содержит предварительный Python-каркас генератора Clean Twin. **Фазы 0–3 не подтверждены как завершённые**: исходное техническое задание и критерии приёмки в репозитории отсутствуют, а реализация и тесты требуют проверки. Фазу 4 не начинать без отдельного указания пользователя.

## Документация для продолжения работы

- [Контекст и передача работы](docs/HANDOFF.md) — состояние, ограничения, история и следующие шаги.
- [Отчёт по фазам 0–3](docs/PHASE_REPORTS/PHASES-0-3.md) — что подтверждено файлами и что отсутствует.
- [Технический аудит](docs/PHASE_REPORTS/TECHNICAL-AUDIT.md) — риски и недостатки текущего кода.
- [Журнал работы агента](docs/AGENT_REPORTS/2026-11-21/HANDOVER.md) — воспроизводимые действия и результаты проверки.

Проверка существующих smoke-тестов: `python3 -m unittest discover -s tests/gen -v` (Python 3.11, стандартная библиотека). Успех этих тестов **не подтверждает** корректность генератора или прохождение exit gate.
