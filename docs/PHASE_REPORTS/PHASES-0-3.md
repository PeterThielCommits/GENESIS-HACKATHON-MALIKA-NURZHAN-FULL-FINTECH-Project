- База: `gen/canonical.py`, `gen/money.py`, `gen/rng.py`, `gen/ids.py`, `gen/calendar.py`.
- Профили: `gen/company.py`, `gen/chart.py`, `gen/counterparties.py`, `gen/policy.py`.

- `gen/invariants/model.py` перечисляет 17 строк описаний и пути к отсутствующим контрактам; автоматического набора проверок 17 инвариантов нет.

## Принятие и ограничения

Нельзя объявить фазы 0–3 завершёнными или exit gate пройденным по результатам этих smoke-тестов. Для верификации нужны исходное ТЗ, схемы, официальные определения инвариантов, отчёты и исправление обнаруженных рисков. Прежний отчёт ассистента о завершении фазы 3 был преждевременным.
