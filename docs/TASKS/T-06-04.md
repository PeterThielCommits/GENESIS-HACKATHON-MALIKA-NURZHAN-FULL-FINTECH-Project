## Goal

Implement the exact three-level matching objective: maximum matched
pairs, then minimum total absolute amount error, then deterministic
lexicographic tie-break on the sorted pair tuple. TP/FP/FN are defined
only here (REQ-SCORE-001); no truth is matched twice; duplicates/splits
cannot inflate TP.
