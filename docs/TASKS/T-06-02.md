## Goal

Implement typed-ID canonicalisation (NFC, namespace check, sort, dedupe;
prefixes never stripped) and strict boundary validation of findings and
truths in `scoring/canon.py`.

## Acceptance criteria

- Unknown namespace / ambiguous / malformed IDs make the finding invalid
  with a precise bounded error (never silently repaired).
- `tests/scoring/test_canon.py` covers valid IDs, NFC behaviour, sorting,
  dedupe, namespace collision safety, schema rejections (bad type,
  untyped IDs, bool amount, extra field) and error index reporting.
