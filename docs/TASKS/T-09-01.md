# T-09-01 — Phase 9 task 9.1: Implement policy JSONL protocol

- **Phase:** 9 (ПРОЦЕССЫ, SEALED EVALUATION И RECEIPTS)
- **Status:** DONE
- **Requirements:** REQ-ARC-006, REQ-ENV-030..032, REQ-SEAL-002
- **Owner:** Zone 2 (`harness/`)
- **Dependencies:** Phase 1 frozen `tool_request`/`tool_response` v1.0.0 schemas, Phase 5 `env/jsonl_server.py`

## Goal

Define and enforce a deterministic, bounded-size JSONL v1.0 pipe protocol between the `harness` coordinator and an isolated `policy` subprocess over `stdin`/`stdout`.

## Acceptance criteria

- Canonical JSONL envelope frames (`reset`, `response`, `terminate`) and `tool_request` validation implemented in `harness/protocol.py` and `harness/policy_process.py`.
- Outbound leakage guard (`assert_policy_outbound_clean`) prevents private markers (`truth.json`, `provenance.json`, `sealed/`, `truth_commitment`, canary tokens) from reaching `policy` stdin.
- Bounded line reads (`MAX_JSONL_LINE_BYTES = 65_536`) and strict protocol version checks (`"1.0"`).
- Reference and adversarial JSONL v1.0 policy subprocesses implemented in `harness/reference_policies.py` (`silent_v1`, `rule_auditor_v1`, `truncate_exhaust_v1`, `malicious_probe_v1`).
