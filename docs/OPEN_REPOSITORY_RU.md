# Как открыть TwinLedger

1. Откройте репозиторий: https://github.com/PeterThielCommits/GENESIS-HACKATHON-MALIKA-NURZHAN-FULL-FINTECH-Project
2. Скачайте его через **Code → Download ZIP** и распакуйте, либо клонируйте через Git.
3. Установите Python 3.11, откройте терминал в папке проекта и выполните:

   ```bash
   python3 tools/demo_server.py --host 127.0.0.1 --port 8000
   ```

   В Windows при необходимости используйте `py -3.11` вместо `python3`.
4. Откройте http://127.0.0.1:8000 в браузере, выберите язык и кейс, нажмите «Запустить анализ».
5. Для остановки сервера нажмите Ctrl+C в терминале.

Данные демонстрационные и синтетические. Не публикуйте сервер в открытом интернете и не загружайте реальные финансовые данные. Подробности и команды проверок — в [README](../README.md).
